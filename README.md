Sales Performance Dashboard

Project Overview

This project presents an interactive Sales Performance Dashboard built in Microsoft Excel to analyze sales transactions, customer activity, product performance, and order trends.
Dataset

The dataset contains 1,200 sales orders covering January 2023 to June 2025, with information on:

• Order date and customer ID

• Products and quantities sold
• Unit and total prices

• Payment methods

• Order status

• Coupon codes

• Referral sources

• Customer and order details

Key Metrics

• Total Revenue: $1.26M

• Total Orders: 1,200

• Units Sold: 3,535

• Unique Customers: 1,189

Dashboard Features

The dashboard provides interactive analysis of:

• Revenue and orders by product

• Revenue by payment method 

• Order status performance

• Referral source performance

• Coupon code performance

• Monthly revenue and order trends

• KPI cards for quick performance monitoring

Tools Used

Microsoft Excel — Data analysis, calculations, dashboard design, KPI cards, charts, and interactive filters.

Objective

The goal of this project is to transform raw sales data into a clear and interactive dashboard that helps stakeholders monitor performance, identify trends, and make data-driven business decisions.
